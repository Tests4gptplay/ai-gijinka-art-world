AI 娘二创视觉设定、社区印象与创作参考资料库。

**建立：2026-10-18｜最近更新：2026-10-27｜14 位模型拟人角色资料＋独立原创人物区**

**许可证：[CC BY-NC-SA 4.0](LICENSE)**（署名、非商业性使用、相同方式共享）。作者与素材来源见 [RIGHTS.md](RIGHTS.md)。

本库研究已存在的 AI 拟人化作品，以 ZipZipPipe 的《大AI和小AI们》和《AI娘化》等作为主要视觉基准，另行注明其他作者的作品。这里不是某一厂商的官方人设，也不把各位创作者的剧情拼成唯一正史。

## 本轮补充了什么

2026-10-27：新增 [AI 拟人二创来源](research/2026-10-27/SOURCE_LEDGER.md)，按作者原帖、独立系列、音乐/视频、Agent 与社区传播保存链接、日期和实际证据范围。沿用既有 14 位角色图鉴及原作署名；[资料更新指引](RESEARCH_GUIDE.md)明确外部角色资料的来源要求和星璃原创测试角色的自由创作例外。

2026-10-25：在 [DeepSeek 人物档案](characters/deepseek.md#长短裙参考图)新增用户提供的**短裙彩色立绘、长短裙黑白对照、长裙彩色立绘**三张参考图，按上传文件原样保存；仓库采用 CC BY-NC-SA 4.0。

逐角色资料覆盖 DeepSeek、GPT、Gemini、Claude、Grok、GLM、Kimi、Qwen、MiniMax、Llama、Seed／豆包、Mistral、混元、MiMo。每页分别写清外形来源、可认人的特征、称呼与梗、基本互动、创作建议及待补内容。

原视频的九人展示已按用户提供的文件取样核对，补齐 MiniMax **00:47** 的可复核位置。Mistral、混元和 MiMo 的图号／原帖与作者归到人物页；不再仅散落于其他项目的说明。

社区资料只提炼大家如何称呼和看待一个角色、能理解什么玩笑以及最低限度的相互认识。world 与 persona 的区别仍是：**world 记大家对她的印象，persona 写她自己的内心与经历。** 学院、公寓、亲缘、恋爱和具体剧情不预先替用户决定。

## 图像与来源

[assets/manifest.json](assets/manifest.json)记录 **12 张既有技术预览及 3 张新增 DeepSeek 参考图**的来源和文件信息。三张新增图片保存在 [assets/deepseek](assets/deepseek/)，在 [DeepSeek 人物档案](characters/deepseek.md#长短裙参考图)集中展示；既有预览覆盖 11 位角色。Mistral、混元、MiMo 的人物页提供精确的固定归档与原帖入口。
