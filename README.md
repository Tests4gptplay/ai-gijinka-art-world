# ai-gijinka-art-world

AI 娘二创视觉设定、社区印象与创作参考资料库。

**建立：2026-10-18｜本轮整理：2026-10-24｜14 位模型拟人角色资料＋独立原创人物区**

本库研究已存在的 AI 拟人化作品，以 ZipZipPipe 的《大AI和小AI们》和《AI娘化》等作为主要视觉基准，另行注明其他作者的作品。这里不是某一厂商的官方人设，也不把各位创作者的剧情拼成唯一正史。

## 本轮补充了什么

逐角色资料覆盖 DeepSeek、GPT、Gemini、Claude、Grok、GLM、Kimi、Qwen、MiniMax、Llama、Seed／豆包、Mistral、混元、MiMo。每页分别写清外形来源、可认人的特征、称呼与梗、基本互动、创作建议及待补内容。

原视频的九人展示已按用户提供的文件取样核对，补齐 MiniMax **00:47** 的可复核位置。Mistral、混元和 MiMo 的图号／原帖与作者归到人物页；不再仅散落于其他项目的说明。

社区资料只提炼大家如何称呼和看待一个角色、能理解什么玩笑以及最低限度的相互认识。world 与 persona 的区别仍是：**world 记大家对她的印象，persona 写她自己的内心与经历。** 学院、公寓、亲缘、恋爱和具体剧情不预先替用户决定。

## 图像与来源

[assets/manifest.json](assets/manifest.json)保留 **12 张技术预览、对应 11 位角色** 的来源、页码与文件记录。本轮新增的是文字档案和索引，不把 14 位档案说成已经存了 14 位高清原图或完整动作包。Mistral、混元、MiMo 的人物页提供精确的固定归档与原帖入口。

DeepSeek 的原型署名链为 **上善无形 → ZipZipPipe 的 DeepSeek 女仆二创**。MiMo 本库采用的立绘和三视图来自 **甶丶**，不统一归给 ZipZipPipe。正常比例稿在部分素材仓叫作 `adult`，这里只是素材分类，不据此推断角色年龄。

Pixiv p10 存在第三方索引冲突：一处称 Gemini 变体，另一处归为 Seed／豆包。本库沿用现有 SEED 对应记录，同时保留双方依据和原站待复核说明；详见 [Seed／豆包档案](characters/doubao.md)。

## 当前资料边界

| 内容 | 当前情况 |
|---|---|
| 14 位模型拟人角色 | 均有独立文字档案和精确参考入口；资料充分程度各异 |
| 视频九人展示 | 已观察指定时间样本，记录画面信息；未声称逐帧审看全部视频 |
| 常见称呼与梗 | 保留代表原帖、作者、日期和实际读取范围；转贴不算独立创作 |
| 统一性格与固定关系 | 许多人物证据不足，明确留空，不用单篇私设填满 |
| 原作图像 | 既有预览保留；本轮未重新取得全部高清原图、原版三视图或透明 Q 版 |
| 动画 | 已整理动作与衔接参考；没有把单张立绘、表情拼图当作完整动画 |
| 原创人物 | 保留独立创作记录，不反向当作社区原作证据 |

第三方图像与视频按各自作者声明和来源处理，详见 [RIGHTS.md](RIGHTS.md)。本轮未公开搬运用户上传的原视频或其研究截帧。仓库里的第三方缩略图、原创生成图和文字研究各有不同身份，不混称为同一套素材许可。
