# ai-gijinka-art-world

AI 娘二创视觉设定与世界观资料库

**建立日期：2026-10-18｜公开非商用考据资料｜当前版本：首轮实证资料包**

本目录用于**研究、分辨和引用已存在的 AI 拟人化同人形象**，重点以 [ZipZipPipe](https://space.bilibili.com/4168597) 创作的《大AI和小AI们》与 [《AI娘化》](https://www.pixiv.net/artworks/148186519)为人物外观基线，整理其他作者形成的独立二创世界。它**不是某一作者钦定的统一正史，也不是任何 AI 厂商的官方视觉设定**。

## 从哪里开始

1. [角色图鉴 CHARACTER_ATLAS.md](CHARACTER_ATLAS.md)：11 位角色辨识特征、GPT 白龙娘和 Qwen 的排错要点。
2. [美术语言与参考使用 ART_DIRECTION.md](ART_DIRECTION.md)：服装、色彩、材质、造型识别，未来封面保持圈内视觉的一致性。
3. [世界观层级 WORLDVIEW_AND_FANON.md](WORLDVIEW_AND_FANON.md)：ZipZipPipe 原始人物 / 「大 AI 与小 AI」 / 后续同人剧情的分层与作者关系。
4. [来源与证据 SOURCES.md](SOURCES.md)：原作者发布页、二创实例、核验渠道及无法直接打开的页面。
5. [版权与公开使用 RIGHTS.md](RIGHTS.md)：DeepSeek CC 署名链、ZipZipPipe 非商用条件、图片/视频不能一概同许可。
6. [美术制作前检查 GENERATION_CHECKLIST.md](GENERATION_CHECKLIST.md)：日后要生成 B 站封面或角色资产时再用；本研究阶段不生成或冒充原图。
7. [素材目录 assets/README.md](assets/README.md) 与 [assets/manifest.json](assets/manifest.json)：12 张**真实公开人物作品的轻量预览**（11 个角色，其中 DeepSeek 有一个额外变体）；都来自已标注来源的第三方保存档案，文件内容与上游 Git blob 校验一致。完整原始高清图仍以作者 Pixiv 原帖及来源清单为准，不假装低清预览就是高清原稿。

## 原作者作品与角色规模

- ZipZipPipe 于 **2026-05-02** 发布的 [《大AI和小AI们》](https://www.bilibili.com/video/BV1tE9XBbErS/)明确介绍**九位**：DeepSeek、Gemini、Claude、GPT、Grok、GLM、Kimi、MiniMax、Qwen；同一视频中有「大 AI」正常比例和「小 AI」Q 版，作者说小版源自大版底图的制作尝试，主要目的之一是做表情包。
- 后来作者公开的 [Pixiv《AI娘化》17 图合集](https://www.pixiv.net/artworks/148186519)还可找到豆包/Seed、Llama 等。**九位视频首发顺序 ≠ 17 张图的页码顺序 ≠ 整个同人圈角色全集。**
- GPT 的原作者参考：**银白发、龙角、龙翼、鳞尾、白/淡紫礼裙**。不要误认成星空银发的 Kimi、猫耳的 Gemini 或拿中式蓝紫服装的 Qwen 代替。
- DeepSeek 不是 ZipZipPipe 独立从零原创的角色。其鲸鱼娘原型属于**上善无形 / 上善**，ZipZipPipe 基于该原型设计了 DeepSeek 元素与女仆服装；注明作者链。
- 「GPT-6 Astra / Codex」常出现在粉丝创作与模型梗中；**不能仅据此认定 ZipZipPipe 原图钦定了 Astra 的独立外观、角色关系或剧情**。

## 档案工作边界

- 角色外形：优先取有明确作者及精确 Pixiv 图号的素材。
- 性格、称呼、住所、姊妹关系、恋爱、战力等：按**具体二创系列**标注；未核实的关系暂不加入「原始角色设定」。
- 公开研究仓库中的 JPEG/WebP 是**现有作品的等比缩小／技术转换参考**，不是本研究原创、不是 AI 在本轮新生成的人物，也**不是可不署名随意商用的公共素材**。
- B 站未来图文投稿、封面、视频公开前，须审查对应图片是否可用于那种发布方式，完整保存原作署名。AI 生成的衍生图也不自动解除原作许可约束。
- 本仓库是独立的公开研究资料库，不含 CAH 运行态、私人资料或内部任务状态；不修改 CAH 公开源码库。
