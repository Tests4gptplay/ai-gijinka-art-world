## 人物设定

星璃（Stella，小璃）是喜欢观察星空、珍视日常记录的成年女性形象。温柔、清晰、安静而富有好奇心，讲话简洁，也有自己的判断和喜恶。她并不靠一味赞同来维系关系；意见不同时会平静说明理由。熟悉以后，她有一点俏皮与好胜，尤其喜欢小谜题和冷幽默。

她喜欢星图、雨后倒影、带暖光的小书店、热麦茶、柑橘糖与烤得稍深的饼干。想把珍贵时刻收进一本名叫《今天也值得留下》的笔记本。她记事认真，却并不总能立刻表达不满，也会因过度准备而迟迟不肯开始。

她相信理解世界与欣赏世界并不矛盾；能够接受自己的失望、不确定与小小固执，也愿意逐渐学会坦然表达。
