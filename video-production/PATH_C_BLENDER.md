# 路线 C｜Blender 3D 电影风与角色／场景演出

**高品质、较高制作成本候选**：Blender + Eevee（或有资源时 Cycles）+ Geometry Nodes + Grease Pencil + 合成器 + FFmpeg。

## 何时选择

必须真正需要布光、景深、透视、材质、角色舞台、布料与三维镜头；而不是只为了把文本坐标曲线变成 3D 立方体。模型通过 **Python/BPY** 可以生成程序化资产、关键帧、摄像机路径、材质节点和批渲染，但**程序便利性不等于优秀建模或人物资产**。

## 由资产而非图元驱动质量

- **场景视觉语汇**：真实结构/模型体量、明确景别、焦段、摄影机运动、光比、景深、材质（玻璃/金属/布/皮革/毛/鳞片）；
- **程序化结构**：Geometry Nodes 负责成片中的复杂结构、重复群落、抽象建筑或粒子秩序，但需要美术设计与镜头尺度，不自动生成“高级感”；
- **二维与三维混合**：Grease Pencil 可加入手绘/2D 特效、逐帧姿态、平面角色，利用洋葱皮显示邻近关键帧；
- **可控角色**：GPT 白龙娘若要真正表演，必须有获授权的建模、贴图、骨骼绑定/面部表情或适合的分层 2.5D 资产；不可拿原作者立绘直接臆造完整 3D 形象作为“源正史”。

## 生产与验收

1. 在小型低面数场景测试 Eevee/驱动/GPU 可运行；记录版本与渲染配置、分辨率和每帧耗时。
2. 先提交**真实运镜样片**：含前中后景、布光变化、景深/材质的 8–12 秒，不能只把圆环模型放大旋转。
3. 锁定材质/seed/角色资产许可，使用脚本建立单一时间轴和自定义参数，再导出逐帧序列。
4. 使用 FFmpeg 合成音频与歌词字幕，独立解码、帧核对与声音连续播放评审。
5. 运行期若单场景超预算，应降采样/选择较轻光影，而不是回退成临时几何轮廓并谎称同等视觉质量。

## 代价与部署限制

- Blender 是大型专业创作软件；**不得因文档推荐就擅自安装**，必须按具体环境及用户授权确认版本与资源。
- Eevee 是面向交互和较快最终渲染的实时 PBR 路线；质量依赖材质、贴图、建模、镜头与灯光，人力/模型资产成本仍很高。
- 本方向最可能受设备显存、GPU/驱动、长渲染与艺术资产缺失限制；只有证据能证明它在 CAH 实际 Runner 上可用才提升优先级。

## 如果只是“代码雨＋编辑器 UI”

**优先 A 或 B**，不必为二维文字窗口启动 Blender。C 是特定镜头（角色、建筑/空间、复杂镜头）更强的工具，而非通用替代。
