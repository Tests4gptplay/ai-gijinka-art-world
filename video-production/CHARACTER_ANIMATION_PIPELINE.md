# 角色驱动的 2D/2.5D/3D 演出生产链

这是针对 AI 娘人物 PV 的**跨路线资产约束**，不是替外部作者自行创造新官方人设。

## 角色“身份锚点”优先于渲染器

[本仓角色图鉴](../CHARACTER_ATLAS.md) 已把 ZipZipPipe 的 GPT 白龙娘与 Qwen/Gemini/Kimi 区分：银白发、**双龙角、浅紫膜翼、白鳞尾、白紫礼裙**；其他角色需各自保存种族/服饰/器物身份。模型输出再华丽，如果把 GPT 画成泛银发仙女或 Qwen 的中式折扇角色，即为角色一致性失败。

### 分层资产建议（研究规格）

```text
character/<id>/
  provenance.md          原作者/许可/参考页
  design-sheet.*         仅使用有权引用/自作的设定卡
  layers/                发/脸/眼/嘴/躯干/衣袖/翼/尾/配饰等
  rig/                   各自骨骼/mesh deform/参数驱动
  action-clips/          表情/肢体/镜头动作
  qc/                    视觉基线和模型输出错误案例
```

各层应是合规重新创作或经明确许可分层的原始素材，不将现有立绘冒充已经完成分层 rig。记录资产 sha、源角色来源和作者署名，避免同名 GPT 在不同粉丝宇宙里的不同服装混进同一镜头。

## 动画方法按效果选

- **A/B：2.5D 分层图与 shader**。初期高性价比：每层有独立锚点、关节/路径、呼吸、眼睛、嘴形、龙翼展开、尾巴运动。三分半钟整片不必每帧独立生成一张新立绘，但关键姿态需要经过角色 QA。
- **C：Blender 3D/Grease Pencil**。更丰富运镜、镜头/手绘组合。建模、绑定、贴图、材质需单独迭代；角色一致性可强于无限 prompt 重新画人。
- **D：Godot 的 AnimationPlayer / SceneTree**。适合具有故事、角色站位、UI/对话演出的 PV，后续可扩展交互版本。
- **专业角色绑定工具如 Live2D Cubism**：可探索但属于需事先核实安装、编辑器授权与部分发布情景的单独路径。Cubism SDK 的发布授权并非一概免费或无条件适用，视频、可扩展软件、公司使用需查官方协议。

## 角色动作 QC 必须看连续短片

三种随机时间点静态帧无法说明表演质量。对整段 8–12s 样片至少检查：表情语义、角色轮廓、衣袖穿插、翼/尾数量、全帧身份一致、camera crop、运动节奏、连续接缝。不同审片者不知道“这是哪个渲染器”，只看实际视频。不可用“已通过像素范围测试”替代动作自然感与情绪。
