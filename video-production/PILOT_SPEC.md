# 小样片选型实验任务书（尚未执行）

## 任务意图

用小样片证据选择高品质程序化视频路线，而不是为了实现某段代码证明某个工具“能用”。它应服务 AI 娘圈的角色 PV、代码雨/多窗口/叙事 UI 风格、完整音乐 MV，并**从根本上防止暗色背景几条曲线摇摆被验收成高水平动画**。

## 统一输入 / 场景

- 暂用**自制点击节拍/无版权音频**作为公开实验基准（8–12 秒），或在经授权的独立本地制作环境中使用合法音乐；**不要把 Mili/其他第三方音轨复制进公共 repo**。
- 用完全原创 UI / 字体/抽象场景和自制临时角色占位图做测试；**不从已收录的 ZipZipPipe 预览 JPEG 强行抠图冒充获得分层授权**。
- 小样片展示一个三阶段小叙事：起始可读终端或 IDE 处理信息 → 一次明显的视觉世界变化（空间/粒子/窗口破壁）→ 一个清晰的结尾镜头/情绪落点。
- 输出：至少 1920×1080/30fps（若资源不够先以 1280×720 做原型再实际测试 1080p），两种独立方式。
- 工作分工与出片状态需真实记录：`candidate` 不等于 `accepted`。

## 三条先行线（不是必须全上）

**A**（浏览器 3D 与 UI 融合）和 **B**（程序化 2.5D Motion Design）为强制首批对照候选；若前两者对镜头设计确实欠佳，再按照**需要更好的空间**用 C，或**需要游戏场景交互**用 D，或者**需要高质背景/特写**用 E。不能为凑路线数量安装大软件。

## 实验步骤与中间产物

### 可选交叉实验：资产先行（源于《千本樱》案例）

当目标需要真实角色/建筑时，在 A/B 的小样对照之外可加入一条**受控资产先行合成样片**：[模型生成/手制合规角色资产 → 可许可的图像修订 → 独立 3D 场景 → Remotion 时间轴合成](PRODUCTION_PATTERN_ASSET_FIRST_COMPOSITE.md)。此线路**不是**先在运行中的 CAH/现有 MV 上改造；必须另有未来实验授权，当前没有安装 Blender MCP/ComfyUI/GPT Image、没有网关/API 权限，也没有实际镜头 QA。不得从[作者公开视频](CASE_STUDY_SENBONZAKURA_OPUS_20261017.md)抓角色图或背景来充当实验资产。选型比较以同样有意义的**实际连续短片**为基础，不给额外工具条数加分。


1. **脚本化创意需求**：不规定是“代码雨”还是“角色立绘”，写清可感知的开端、变化、落点、镜头/排版/字体目标。
2. **安装/后端审查**：探测已存在的 Node、Chromium/GPU、FFmpeg、字体、磁盘空间、GPU显存；所有未知写 `UNKNOWN`，未经许可不装 Blender/Godot/ComfyUI/商业工具。
3. **生成短片**：所有路线生成真正时间轴驱动的高质量画面与实拍编码 MP4；图像/视频生成模型参与则明示。
4. **盲审视频**：两版最终 MP4 使用一致播放器/显示比例，无方案名称的审片者按 [QUALITY_GATE](QUALITY_GATE.md) 评价；存实际观测和时间码，不以抽帧接触图替代看运动。
5. **精选稳定路径**：同时考虑镜头表现力、中文字体/字幕稳定性、角色一致性、脚本复杂度、渲染速度、工程复用性与权利/授权。
6. **扩展试验**：优胜方案才做 20–30 秒、真实结构更多的镜头，证实没有越长越重复；最终再考虑整曲编排与生产。

## 必须回传的证据

| 文件（建议命名，非本次已创建） | 内容 |
|---|---|
| `brief.md` | 单一小样的视觉意图和实际场景目标 |
| `shot-manifest.json` | 镜头、fps、start/end、时钟、素材 id |
| `probe-gpu-env.json` | 浏览器/GPU/FFmpeg 实际探测 |
| `candidate-A.mp4` / `candidate-B.mp4` | 真正音画合成的原始 MP4，非 PPT |
| `encoded-contact-A.jpg` / `...B.jpg` | **从真实 MP4** 截帧，注明时间码 |
| `blind-review.md` | 至少一位独立审片者看到完整连续运动后的发现 |
| `final-decision.json` | `SELECT_A/B` 或 `REWORK_ALL`，理由、未解决风险 |

材料保存在有授权的独立实验区；**原先 CAH 成片和软件环境不是当前项目的执行场地**，除非以后另有明确的项目实施范围。公开 repo 最终只放许可安全的说明、经过审查的合成样片与脱敏结果。

## 本轮不做

没有投递 CAH Planner/Worker、没有改动已运行的 MV，没有创建新的工作流或安装软件、没有生成可播放新视频。任务是前期方案准备，状态只能写 **RESEARCH_READY / EXPERIMENT_PENDING**。
