## 结论先行

本案例最值得学习的不是一句万能 Prompt，也不是“Blender 比代码渲染必然好”，而是 **由语言模型主导分镜和审片、成熟专业软件提供高表现力资产、Remotion 做可控时序与最终画面合成** 的合作模式。

原稿的“代码合成 7574 帧”是 **composition/output 方法**：可以合成 Blender 场景、ComfyUI 角色图片、修订过的图像、字体与其它视觉层；**不能理解为画面内容全部由代码画出，也不能称作未使用图像生成模型**。这和另一条纯 Three.js/GLSL 无生成图模型的《world.execute(me);》案例有显著区别。

## 三、哪些技术特性可以单独验证

- **Remotion**：官方以 React 组件 + `useCurrentFrame()` 按确定帧编号合成，支持文字/图片/视频/音频、分镜 `Sequence` 与 CLI 导出；因此适合作为混合媒体**统一时间轴**，不要求输入资产全是程序几何。
  - [核心机制](https://www.remotion.dev/docs/idea) · [Composition](https://www.remotion.dev/docs/composition) · [Render](https://www.remotion.dev/docs/render)
- **Blender MCP**：公开第三方实现 [MCP for Blender](https://github.com/ahujasid/mcp-for-blender)支持模型查看场景、创建/修改对象、编辑材质及通过 Python 操作 Blender。**它只是公开可行实现之一，不证明作者使用的正是这个项目**。MCP 客户端连到 Blender 的路径需独立权限/安全评审。
- **Anima**：Comfy Org 确有 [Text to Image (Anima) 官方工作流蓝图](https://github.com/Comfy-Org/ComfyUI/blob/master/blueprints/Text%20to%20Image%20%28Anima%29.json)；[CircleStone Labs Anima 模型卡](https://huggingface.co/circlestone-labs/Anima)描述其偏向动漫插画，**权重采用独立的非商业许可证**；模型卡同时说明 **Outputs 的许可待遇不同于权重**。作者是否用这组确切权重尚需原工程核实。
- **GPT Image**：[OpenAI 图像编辑文档](https://developers.openai.com/api/docs/guides/image-generation)支持多参考图、局部 mask 与透明背景等输出选项。mask 是引导而非精确像素剪刀，人物头发/衣边/翅膀仍需人工或算法检查；具体投稿使用哪个模型版本未知。
- **许可与素材**：工具代码许可证、Anima 模型许可、生成的素材权利、初音形象/歌曲权利是不同层面。作者说明注明原曲创作/演唱者和非商业二创，**这不是本仓获得原曲再分发许可**。

## 四、相对「所有内容程序画几何形状」的重要经验

- **表现问题交给适合的工具**：环境/建筑交给可布光可定镜头的 3D 建模；人物交给可维持形象的插画生成/精修/分层；歌词与运动交给稳定编排工具。
- **先做美术资产，再进时序合成**：当主角长相和画面语言先确定时，模型不用在每一帧重新即兴创造角色，也无需用长方形充当“角色”。
- **风格统一是一条独立管线**：修图、色调、线条风格、边缘质量、光影方向、噪声颗粒与 UI 字体的一致性，比是否统一使用一个生成模型更重要。
- **编排粒度仍然可以精确到帧**：Remotion 输出的是固定时间轴；高细节角色图可以作为动画层反复使用，在时间轴内做关键帧运动、遮罩、位移、镜头与转场。不必每帧都调用图像生成 API。
- **真实审片不能省**：角色比例/色彩/视线、跨镜头连续性、动画节奏、画面的历史/文化叙事等即便资产很漂亮也可能失败。评论区有审美反馈并不等同于独立质量认证。
- **已有工具是重要输入**：“需要什么工具直接下”是作者自己的单次授权/环境，不是所有代理的默认安全规则；正式制作系统只能在已确认可用的软件及用户另行授权范围内自由选择。

## 五、与本仓现有五路线的关系

不是第六种独立渲染器，而是 **A（Remotion）+ C（Blender）+ E（ComfyUI 图像素材）+ 独立图像精修** 的跨路线组合范式。[资产先行合成模板](PRODUCTION_PATTERN_ASSET_FIRST_COMPOSITE.md)讨论未来如何使其更可复用；角色要求见 [角色生产链](CHARACTER_ANIMATION_PIPELINE.md)，真正的质量准入见 [QUALITY_GATE](QUALITY_GATE.md)。

这种路线很适合 AI 娘圈角色 MV / PV：角色形象细节不能由程序画几何轮廓替代；复杂镜头又不适合完全依赖随机生成视频。**但是否在我们的机器上表现得更好、成本是否合理，目前均未实测**。
